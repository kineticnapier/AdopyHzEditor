# AdopyHzEditor v1.0.0

初めての製品版です。v0.8.0 から約1100件の変更をまとめました。

## 新機能

### キック音高解析
- キックなど短い音の音高を追跡して、Curve Note にできます（設定パネル →「キック音高解析」）。
- 範囲は、スペクトログラムの上でキックの音高線を四角で囲むだけで指定できます。離すとすぐ解析します。
- 方式は3つあります。
  - **倍音解析**：音高が安定した音向けです。
  - **1周期ごと**：音高が速く上下する Zaag 向けです。
  - **一番明るい線**：高い音やシンセのスイープ向けです。
- 「1本につなげて近似」で、途切れた解析結果をつながった1本の線にできます。最大本数を1にすると、曲線1個で近似します。

### ADOFAI 書き出し
- **既存の譜面への追記（標準）**：選んだ .adofai の最後に、タイルを足します。
  - 元の譜面の設定とイベントはそのまま残ります。
  - 追記した部分は、単独で書き出したときと同じタイミングで鳴ります。
  - 元のファイルは `.adofai.bak` に保存してから上書きします。
- **Harmony / 比率ポリリズム**：
  - 重なったノーツから和音を作るようになりました。
  - 音の高さに合わせた周期と、曲の拍に合わせた周期を選べます。
  - 和音の音数と細かさに上限を付けられます。
- **ノーツの連結**：隙間なく続くノーツは、1本につなげて書き出します（境目で切りません）。
- **タイル数**：タイル数の上限をなくしました。和音が密な曲でも速く書き出せます。
- **ルート**：自動ルートの Twirl 計画と、隙間をつなぐ処理を足しました。
- **音源**：書き出しに使う音源を、解析に使った音源とは別に選べます。

### 編集
- 選んだノートを1オクターブずつ上げ下げできます（Ctrl+Shift+PageUp / PageDown）。音名を変えずに、Hz譜面の速さを半分や2倍にできます。
- MIDI を読み込むときに、どのトラックを読み込むか選べます。読み込んだトラックはレイヤーとして残り、オン・オフを切り替えられます。
- カーブの形のプリセットと、カーブの範囲カットを足しました。

### 解析・表示
- Vorbis Direct（実験）：OGG のスペクトルを直接読み込みます。
- エディタの画面とレイアウトを全体的に見直しました。

## 改善
- 大きな譜面での編集が4〜5倍速くなりました。ノート2万個で、1回の操作が約0.5秒から約0.12秒になりました。
- 未保存の変更を守る仕組みを強くしました。保存は途中で失敗しても壊れない書き方になり、閉じる前に確認します。
- ADOFAI Kick の試聴音は、製品版に同梱した抽出ツールでゲームから取り出します。.NET を入れる必要はありません。
- 書き出しダイアログを整理しました。あまり使わない設定は「詳細設定」と「和音の詳細」にたたんでいます。
- ヘルプに、追記書き出し・キック音高解析・オクターブ移動の説明を足しました。

## 修正
- ウィンドウを閉じても、プロセスが残ってコンソールに戻らないことがあった問題を直しました。
- 終了時にコンソールへ「QDxgiVSyncService not destroyed in time」が出ていた問題を直しました。
- このほか、編集・再生・解析・書き出しの不具合を400件以上直しました。

## 削除
- 旧 PySide6 版のアプリ（`main.py`）を削除しました。v0.8.0 から、配布しているのは Web UI 版だけです。
- CQT解像度の「41平均律」「53平均律」を削除しました。これを使っていたプロジェクトは「自動」として開きます。

## 互換性
- v0.8.0 のプロジェクトファイルはそのまま開けます。
- タイルを `pathData` で持つ古い形式の ADOFAI 譜面には、追記できません。ADOFAI で一度保存し直してから選んでください。
